# Support

Use the repository issue tracker for reproducible problems with examples,
documentation, or firmware packages.

Include the product name and revision, example path, framework and exact
version, host operating system, reproduction steps, expected behavior, actual
behavior, and relevant build or serial logs. For hardware issues, include the
power source, antenna, region, connected peripherals, and a clear photo when
useful.

Remove LoRaWAN keys, device credentials, tokens, account identifiers, and
private network details before attaching logs. Product purchase, warranty, and
official documentation links will be added when their public URLs are
confirmed.
