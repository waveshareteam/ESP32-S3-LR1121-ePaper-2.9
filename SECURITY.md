# Security Policy

Do not report credentials, private keys, LoRaWAN session material, or other
sensitive data in a public issue.

Until a dedicated security contact is published, report suspected
vulnerabilities through Waveshare's official support channel and identify this
product and the affected repository path. Public support URLs will be added
after they are confirmed.

Security reports should include affected versions, impact, reproduction
conditions, and whether radio, firmware update, stored credentials, or host
tools are involved. Avoid publishing exploit details before maintainers have
had a reasonable opportunity to assess the report.
